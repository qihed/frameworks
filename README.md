# Сервис учёта комиксов

**Репозиторий:** https://github.com/qihed/frameworks

## Назначение

Консольное приложение для ведения личной коллекции комиксов. Сервис
позволяет пользователю просматривать доступные серии, добавлять их в
свою коллекцию, отслеживать статус и прогресс чтения, а также хранить
эти данные между запусками программы.

Решаемая задача: у читателя комиксов коллекция растёт и разрастается по
разным сериям, из-за чего он теряет представление о том, что уже
прочитано, что отложено, а что стоит начать читать. Сервис собирает эти
сведения в одном месте.

## Целевая аудитория

Читатели и коллекционеры комиксов, манги и графических романов, которые
следят сразу за несколькими сериями и хотят вести учёт собственной
коллекции.

## Предметная область

Основными объектами предметной области являются:

* **серия** — цикл комиксов с названием, издателем, автором, общим
  числом выпусков и возрастным ограничением;
* **запись коллекции** — отметка о том, что пользователь добавил серию
  в свою коллекцию: статус чтения, количество прочитанных выпусков и
  признак удаления записи из коллекции.

Пользователь может добавить серию в коллекцию, если она ещё не
добавлена и возраст пользователя не меньше возрастного ограничения
серии. Удалённая из коллекции запись не удаляется физически, а
помечается как неактивная и не блокирует повторное добавление серии.

## Основные сущности

### Серия (`series.py`)

Атрибуты: `id`, `title`, `publisher`, `author`, `issues_total`,
`age_limit`.

Основные функции:

* `add_series()` — добавление серии в коллекцию доступных серий;
* `find_series()` / `find_series_by_id()` — поиск серии по названию или
  идентификатору;
* `check_series_age_limit()` — проверка доступности серии по возрасту;
* `filter_series_by_age_limit()` — отбор серий по возрастному
  ограничению;
* `sort_series_by_issues()` — сортировка серий по количеству выпусков;
* `show_series()` — вывод списка серий.

### Запись коллекции (`collection.py`)

Атрибуты: `id`, `series_id`, `status_code`, `issues_read`,
`is_removed`.

Функции `get_status_name()`, `can_add_to_collection()`,
`calculate_progress()` и `count_issues_left()` перенесены из начального
сценария ПР1 без изменения их назначения.

Основные функции:

* `is_series_in_collection()` — проверка наличия активной записи по
  серии;
* `add_to_collection()` — создание записи коллекции с проверкой
  доступности серии;
* `remove_from_collection()` — пометка записи как удалённой;
* `update_issues_read()` — обновление количества прочитанных выпусков;
* `get_collection_status()` — текстовое сообщение о доступности серии
  для добавления;
* `format_collection_entry()` / `show_collection()` — вывод записей
  коллекции.

## Основные операции

### Работа с сериями

* добавление серии;
* поиск серии по названию;
* проверка возрастного доступа;
* фильтрация по возрастному ограничению;
* сортировка по количеству выпусков;
* просмотр списка серий.

### Работа с коллекцией

* добавление серии в коллекцию;
* проверка доступности серии перед добавлением;
* обновление прогресса чтения;
* удаление (отмена) записи коллекции;
* просмотр списка записей коллекции.

При добавлении в коллекцию проверяется, что серия ещё не добавлена
активной записью и что возраст пользователя соответствует возрастному
ограничению серии.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

* `data/series.json`;
* `data/collection.json`.

Чтение и запись файлов выполняются в модуле `storage.py` через
контекстный менеджер `with`. Отсутствие файла или повреждённые данные
не приводят к аварийному завершению программы: обрабатываются
исключения `FileNotFoundError` и `json.JSONDecodeError`, а работа
продолжается с пустым списком данных.

Некорректный ввод пользователя (не число, пустая строка, неверный
формат даты) обрабатывается функциями модуля `utils.py`, которые
повторяют запрос до получения корректного значения.

## Назначение модулей

* `main.py` — точка входа: главное меню и пользовательские сценарии;
* `series.py` — функции работы с сериями комиксов;
* `collection.py` — функции работы с записями пользовательской
  коллекции;
* `storage.py` — загрузка и сохранение данных в JSON;
* `utils.py` — безопасный ввод целых чисел, дат и непустых строк;
* `tests/` — автоматизированные тесты `pytest`.
